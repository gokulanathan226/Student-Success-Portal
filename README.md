
# Student Success Portal

## Project Overview
Student Success Portal is a web-based application designed to help students manage their academic activities in one place.

## Features
- Dashboard with study progress summary
- Attendance percentage calculator
- Marks percentage calculator
- Study planner with task deadlines
- Task completion tracking
- Progress analytics
- Smart study recommendations
- SQLite database for persistent task storage
- Input validation for attendance and marks

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite

## Requirements
- Python 3
- Flask
- Web browser
- Visual Studio Code (recommended)

## How to Run the Project

1. Open the project folder in VS Code.
2. Open the terminal.
3. Install Flask:

   pip install -r requirements.txt

4. Run the application:

   python app.py

5. Open this URL in your browser:

   http://127.0.0.1:5000

## Database
The application uses SQLite to store study tasks and their completion status.

## Project Objective
To help students organize their study tasks, monitor academic progress, and develop consistent study habits.
